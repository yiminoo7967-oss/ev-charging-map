# 전기차 충전 지도

브라우저에서 index.html을 열면 충전소 목록과 운영사 요금표가 자동으로 표시됩니다. 지도와 데이터가 앱 폴더에 들어 있어 오프라인에서 사용할 수 있습니다. 자료는 정적 목록입니다.

Windows에서 주제곡을 앱 안에서 들으려면 `Start.cmd`를 더블클릭하여 지도를 엽니다. 상단의 **실행 · 주제곡 재생**을 누르면 YouTube 플레이어가 열립니다. 주제곡 재생에는 인터넷이 필요합니다. **닫기**를 누르면 재생이 멈춥니다. 상단의 **번개맨 애니메이션** 버튼으로 움직임을 일시정지하거나 다시 켤 수 있습니다.

- 지역, 충전 방식, 이름, 주소로 조회할 수 있습니다. 지도에는 좌표가 확인된 충전소가 표시됩니다. 좌표가 없는 충전소도 목록에 표시됩니다.
- 충전소 상세에서 해당 운영사의 출력별 안내가와 갱신일을 볼 수 있습니다. 결제 방식, 현장 요금과 할인에 따라 실제 단가는 달라질 수 있습니다.
- 선택한 지역의 충전소와 해당 지역에서 확인된 운영사 요금표를 CSV로 저장할 수 있습니다. 검색어와 충전 방식은 화면에 적용되며 CSV는 지역을 기준으로 저장합니다.

## 기본 자료

- 2025년 8월 7일 기준 전국 충전소 목록의 충전기 등록 445,391행을 운영기관·충전소명·주소로 묶었습니다. 충전소별로 같은 유형과 출력 표기의 등록 대수를 합쳤습니다. 앱에서 사용하는 충전소 ID는 해당 묶음에 부여한 식별자입니다. [한국환경공단 전기자동차 충전소 위치정보](https://www.keco.or.kr/web/lay1/bbs/S1T1385C1392/F/257/view.do?article_seq=84663)
- 좌표는 이름과 주소가 일치하는 공개자료에서 가져왔으며, 한전 자료는 운영기관까지 대조했습니다. 좌표 원본에만 존재하는 충전소도 포함했습니다. 합계 94,916곳이며 이 중 4,546곳에 지도 좌표가 있습니다. [한국전력공사 충전소 위경도](https://www.data.go.kr/data/15102458/fileData.do) · [전북특별자치도 충전소 현황](https://www.data.go.kr/data/15175474/fileData.do)
- 2026년 11월 25일에 대조한 78개 운영사의 공개 안내가를 포함했습니다. 갱신일은 운영사마다 다릅니다. 충전소에 운영사 요금이 연결되지 않으면 확인할 수 없다고 표시합니다. [무공해차 통합누리집 충전요금 안내](https://ev.or.kr/nportal/evcarInfo/initEvcarChargePriceV2.do)
- 지도 경계는 제공된 HangJeongDong_ver20261001.geojson에서 변환했습니다.

## 선택 사항으로 CSV 바꾸기

화면 하단의 **자료 출처 및 CSV 가져오기**에서 직접 갖고 있는 CSV를 사용할 수도 있습니다. 충전소 파일 필수 열은 충전소명, 주소, 위도, 경도입니다. UTF-8과 CP949를 읽습니다. 충전소별 요금 파일에는 충전소ID와 충전단가를 넣습니다. 충전기ID, 적용시작일(YYYY-MM-DD), 요금구분도 지원합니다. 사용자 요금 파일을 추가하면 해당 충전소와 충전기 ID가 일치하는 단가를 표시하며, 요금 CSV 저장에는 그 파일의 연결 행을 사용합니다. 기본 자료 다시 불러오기를 누르면 동봉한 자료로 돌아갑니다.

동봉한 예제 CSV에는 수동 가져오기 확인용 가상 값이 들어 있습니다. 앱을 열 때는 위의 공식 원본에서 준비한 자료를 읽습니다.
